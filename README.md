# 🏰 AventuraMC — Resource Pack

Resource pack officiel du serveur **AventuraMC**.

> **Fusion SAFE 4.42 + Skyblock**  
> Compatible **Minecraft 1.20 → 1.21+**

Ce pack regroupe les ressources visuelles utilisées par AventuraMC : HUD médiéval, interfaces personnalisées, crates, clés, parchemins, outils, contenus Skyblock, assets de donjons et autres modèles/textures custom.

## 📥 Installation

### Pour jouer sur AventuraMC

1. Télécharge la dernière version du pack dans la section **Releases** du dépôt.
2. Garde le fichier au format **.zip**.
3. Lance Minecraft.
4. Va dans **Options → Packs de ressources → Ouvrir le dossier des packs**.
5. Dépose le ZIP dans le dossier `resourcepacks`.
6. Active **AventuraMC Resources** dans Minecraft.

> Si le serveur envoie automatiquement le pack à la connexion, l'installation manuelle n'est normalement pas nécessaire.

## ✅ Compatibilité

- Minecraft **1.20 / 1.20.1**
- Minecraft **1.21+**
- Conçu pour **AventuraMC**
- `pack_format: 15`
- `supported_formats: 15 → 99`

## 🎨 Contenu principal

- HUD médiéval AventuraMC
- GUI / interfaces personnalisées
- GUI Skyblock
- Crates et clés custom
- Parchemins
- Pioches, hammers et outils custom
- Assets du monde donjon
- Mobs / contenus corrompus
- Casino
- Polices et glyphes personnalisés
- CustomModelData conservés pour la compatibilité avec le serveur

## ⚠️ Important

Le fichier `pack.mcmeta` doit rester directement à la racine du ZIP.  
Ne décompresse pas le pack avant de le placer dans le dossier `resourcepacks`.

Pour une utilisation automatique côté serveur, utilisez l'URL directe du ZIP d'une **GitHub Release** ainsi que son SHA-1 dans `server.properties`.

## 🔧 Serveur Minecraft

Exemple :

```properties
resource-pack=<URL_DIRECTE_DU_ZIP>
resource-pack-sha1=<SHA1_DU_ZIP>
require-resource-pack=true
```
